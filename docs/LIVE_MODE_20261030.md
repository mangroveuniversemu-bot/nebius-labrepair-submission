# Direct runtime inference and judge-result visibility / 30 October 2026

## Why this increment exists

The published release contains genuine archived model and Sandbox observations,
but its legacy `provider_envelope.py` only previews a different invoice request.
That module's `NOT_IMPLEMENTED` dispatch status is historical and remains true.
The new `labrepair/live_repair.py` and `scripts/run_live_repair.py` supply a
separate real HTTP transport for the fixed synthetic Bell–CHSH parameter request.

[Official rules section 4](https://nebiusglobalaihackathon.devpost.com/rules),
rechecked 30 October, defines running on Token Factory as making a runtime call
to its inference API. This client follows the [official API endpoint and bearer
authentication](https://docs.tokenfactory.nebius.com/quickstart). The Coding track
also describes agents/developer tools that write, run and test code. Adding this
transport alone is not proof of complete track eligibility or a new end-to-end
coding/Sandbox execution. That remains a separate demonstration requirement.

## Scope

- Preview: zero network requests and no credential access.
- Live: explicit `--live --confirm-provider-billing`, one fixed request,
  `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B`, 64 completion tokens, 30-second socket timeout,
  no retries, no redirects and standard TLS verification.
- The request is bound to the unchanged archived request SHA-256. There is no
  arbitrary URL, prompt, model, command or tool selector.
- The environment key is used only in the Authorization header. Neither it nor
  headers/provider error bodies are logged. A key echo is rejected without saving
  that response. Local run directories are ignored by Git and never overwritten.
- A completed response enters the existing deterministic parameter reviewer.
  A matching repair does not promote the original 3.40 claim. No generated code
  is executed by this client. A new Sandbox run is not included.
- The billing flag is operator acknowledgement, not account verification or a
  hard spending cap. Exact billed currency is recorded as unknown. The repository
  makes no claim that a requested token bound alone prevents charges.

New transport tests use only fabricated keys and mocked HTTP responses. They
exercise successful intake, no-consent/no-key preview, single-call errors,
oversize/secret-echo rejection, truncated/tool/model mismatch rejection, changed
request refusal, redirect refusal and duplicate-run refusal. These are offline
tests, not evidence of a real provider call.

## New direct CLI execution

from source `54fcd8de6647bedda1ef965398821720ddb5aadb`, using its already saved key.
The result was HTTP 200 / MODEL_REPAIR_VERIFIED, 121 input and 38 completion tokens,
0.9245 seconds, no retry and no Sandbox dispatch. The shared persistent ledger
records one of five attempts and USD 0.01 of USD 0.05 reserved in Taipei time.
Actual billed currency remains unknown.

Five exact files are in [the independent direct-run evidence directory](../evidence/nebius-direct-cli-20261030-1/):
request, response, local review, transport receipt and budget status. Desktop
decoded and independently matched each SHA-256, then replayed the received
response through the same deterministic reviewer; it matched the saved review.
The original claim remains NOT_REPRODUCED. No credentials, headers, budget DB or
state anchor are included. These are client-observed records, not provider-signed
attestations or a claim of an account-wide monetary cap.

## Result visibility

The primary judge CTA now waits for computation, clears `aria-busy`, focuses the
descriptive verdict and scrolls the result into view. It respects reduced-motion
preferences. Sample selection alone does not steal focus; blocked computation
reveals a failure without enabling receipts. The portable engine and focused
DOM-contract tests verify this order; actual browser scrolling, speech output
and direct-file download remain unverified by this automation.

The owner's supplied review reports successful desktop/375px HTTP-served checks
and a source-bound download on the prior build. That is external review evidence,
not a browser test performed by this increment. No local-file tool restriction was
bypassed here. The original Python workbench is unchanged.

free, unrestricted judge access through its end. Public source/video/test-build

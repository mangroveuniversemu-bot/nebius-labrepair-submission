## Recording boundaries

- Narration uses the local Kokoro 82M neural voice `af_heart`, not Windows system
  speech. Generic synthetic narration does not impersonate the builder or a
  customer. No paid TTS API is used. See the
  [model license](https://huggingface.co/hexgrad/Kokoro-82M) and
  [ONNX runtime wrapper](https://github.com/thewh1teagle/kokoro-onnx).
- The video combines actual UI captures with clearly labeled editorial evidence
  cards. It is an edited walkthrough, not a continuous screen recording or a new
  cloud run. The complete narration and subtitle timings are separate artifacts.
- Record the application, not account consoles, credential managers, private file
  lists or unrelated desktop windows.
- Keep the synthetic-input and recorded-execution labels readable. The wrong
  control was authored by the operator; it was not a second NVIDIA generation.
- Label 1.273 seconds as the Sandbox operation duration, not end-to-end repair
  latency. Do not infer a billed price from an unconfirmed cost metric.
- The four passing checks belong to the model repair. The baseline's two failed
  checks and the control's one failed check are intended outcomes.
- A hash binds archived bytes; it is not provider attestation or proof of the
  original physical experiment. No physical quantum experiment is demonstrated.
- The current UI reviews curated local cases and plays back a saved actual cloud
  run. It does not submit new provider jobs or demonstrate a fully autonomous loop.
- Public upload, publication and competition submission remain separate decisions.
